# TradeVault — GitHub Pages deployment

Repository URL:
`https://sohan01-business.github.io/trades-journal/`

## Upload
Upload the contents of this folder to the root of the GitHub repository named `trades-journal`.
Do not upload the ZIP itself.

## Enable Pages
After pushing the files:
1. Open GitHub → repository → Settings → Pages.
2. Under Build and deployment, choose **GitHub Actions**.
3. Push to the `main` branch (or use Actions → Deploy TradeVault to GitHub Pages → Run workflow).
4. Wait for the workflow to finish.
5. Open:
   `https://sohan01-business.github.io/trades-journal/`

## Install on Android
Open the URL in Chrome while online, wait for the app to load, then use Chrome's **Install app** / **Add to Home screen**.

## Offline
After installation and one successful online load, turn on Airplane mode and reopen TradeVault from the installed app icon. Normal journal functionality is intended to remain local/offline.
